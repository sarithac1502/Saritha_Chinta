A responsive, static portfolio highlighting experience in SQL, ETL, data migration, data quality, data operations, and healthcare data.

## Files

- `index.html` — page content and section structure
- `styles.css` — responsive layout, typography, colors, and project illustrations
- `script.js` — mobile navigation and automatic footer year

## Run locally

Open `index.html` in a browser. No package manager, build process, or framework is required. The Google Fonts import is optional; the page uses fallback fonts if the external font service is unavailable.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch** if that is how your repository is configured.
4. Select the branch that contains these files (commonly `main`) and the repository root (`/`), then save.
5. Wait for the GitHub Pages deployment to complete and open the live portfolio URL.

If GitHub Pages is already enabled for this repository, replacing the existing files in the configured publishing branch should trigger a new deployment automatically.

## Updating the portfolio

- Edit text and section content in `index.html`.
- Update visual styles in `styles.css`.
- Update navigation behavior in `script.js`.
- Keep project descriptions accurate and avoid publishing confidential client data or proprietary code.

## Portfolio content notes

The featured project cards summarize professional experience. They are not claims that the underlying client systems or proprietary source code are publicly available. Add links to independent demo repositories only after those demos have been created and reviewed.
