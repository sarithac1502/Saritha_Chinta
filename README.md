## Preview locally

From this directory, use either of these approaches:

### Option 1 — Open directly

Open `index.html` in a browser.

### Option 2 — Local HTTP server

If Python is installed:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Publish with GitHub Pages

For a personal GitHub Pages site, the repository should be named:

```text
<github-username>.github.io
```

The GitHub username was not provided, so the exact repository name cannot be determined yet.

After creating the repository on GitHub, run:

```bash
git init
git add index.html styles.css script.js README.md
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/<github-username>/<github-username>.github.io.git
git push -u origin main
```

Then enable GitHub Pages from the repository's **Settings → Pages** area if GitHub has not already enabled it automatically.
